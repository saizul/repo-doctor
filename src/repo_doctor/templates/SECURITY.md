# Security Policy

## Supported versions

Security fixes are made for the latest release of @@PROJECT@@. Please upgrade
before reporting a problem.

| Version | Supported |
| --- | --- |
| latest | yes |
| older | no |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately via @@SECURITY_CONTACT@@. Include:

- a description of the problem and its impact,
- steps or a proof of concept to reproduce it,
- affected versions and configuration.

You will get an answer within 5 working days. We will keep you updated while
we work on a fix and credit you in the release notes unless you prefer to stay
anonymous.
